# مستند پروژه

## معرفی

این پروژه یک پروژه شبکه اجتماعی فیلم بازان بصورت بک‌اند RESTful است که برای مدیریت فیلم‌ها، کاربران و نقدهای کاربران ساخته شده است. در این پروژه کاربران می‌توانند ثبت‌نام کنند، وارد حساب خود شوند، فیلم‌ها را ببینند و برای هر فیلم امتیاز و نقد ثبت کنند. همچنین مدیر سیستم می‌تواند فیلم‌های جدید اضافه کند، آن‌ها را ویرایش کند یا حذف کند.

## فناوری‌های استفاده شده

این پروژه با **Node.js** و **Express** پیاده‌سازی شده و از **MongoDB** به همراه **Mongoose** برای ذخیره اطلاعات استفاده می‌کند. برای احراز هویت از **JWT**، برای هش کردن رمز عبور از **bcryptjs** و برای اعتبارسنجی اطلاعات ورودی از **Zod** استفاده شده است.

## ساختار پروژه

ساختار پروژه به صورت لایه‌ای طراحی شده تا هر بخش مسئولیت مشخصی داشته باشد. ابتدا درخواست وارد Route می‌شود، سپس در صورت نیاز از Middleware ها عبور می‌کند، بعد Controller درخواست را مدیریت می‌کند و در نهایت Service عملیات مربوط به پایگاه داده را از طریق Modelها انجام می‌دهد.

پوشه `Routes` مسیرهای API را نگهداری می‌کند، `Controllers` مسئول دریافت درخواست و ارسال پاسخ هستند، `Services` منطق اصلی برنامه را پیاده‌سازی می‌کنند، `Models` شامل مدل‌های `User`، `Movie` و `Review` هستند و در `Middlewares` نیز احراز هویت، اعتبارسنجی، بررسی دسترسی مدیر و مدیریت خطاها قرار گرفته است.

## قابلیت‌های پروژه

کاربران می‌توانند ثبت‌نام کنند، وارد حساب خود شوند و توکن JWT دریافت کنند. رمزهای عبور قبل از ذخیره شدن در پایگاه داده هش می‌شوند و هر کاربر یکی از دو نقش `user` یا `admin` را دارد.

مدیر امکان ایجاد، ویرایش و حذف فیلم‌ها را دارد و کاربران می‌توانند فیلم‌ها را بر اساس عنوان یا نام کارگردان جست‌وجو کنند. هر کاربر فقط یک بار می‌تواند برای هر فیلم نقد ثبت کند، اما در صورت نیاز می‌تواند همان نقد را ویرایش یا حذف کند. همچنین بعد از ثبت یا ویرایش هر نقد، میانگین امتیاز و تعداد نقدهای فیلم به صورت خودکار به‌روزرسانی می‌شود.

در پروژه برای خطاهای اعتبارسنجی، داده‌های تکراری، پیدا نشدن اطلاعات و مسیرهای نامعتبر نیز پاسخ مناسب در نظر گرفته شده است.

## مسیر های API

پروژه شامل سه بخش اصلی کاربران، فیلم‌ها و نقدها است. مسیرهای هر بخش به صورت زیر هستند.

### بررسی سلامت

```text
GET     /
```

### کاربران

```text
GET      /user
GET      /user/:name

POST     /user/create
POST     /user/login
POST     /user/update/:id

DELETE   /user/delete/:id
```

این مسیرها برای ثبت‌نام، ورود، دریافت اطلاعات کاربران، تغییر رمز عبور و حذف کاربر استفاده می‌شوند.

### فیلم‌ها

```text
GET      /movie
GET      /movie/:slug

POST     /movie/create
POST     /movie/update/:id

DELETE   /movie/delete/:id
```

مسیرهای ایجاد، ویرایش و حذف فیلم فقط توسط کاربر دارای نقش `admin` قابل استفاده هستند.

### نقدها

```text
GET      /review
GET      /review/:id

POST     /movie/:slug/review
PATCH    /movie/:slug/review

DELETE   /review/delete/:id
```

کاربران واردشده می‌توانند برای هر فیلم یک نقد ثبت کنند، آن را ویرایش یا حذف کنند. برای استفاده از مسیرهای محافظت‌شده باید توکن JWT در هدر زیر ارسال شود.

```text
Authorization: Bearer <token>
```

## مدل‌های داده

در پروژه سه مدل اصلی وجود دارد. مدل `User` اطلاعاتی مانند ایمیل، نام کاربری، رمز عبور هش‌شده و نقش کاربر را نگهداری می‌کند. مدل `Movie` شامل عنوان، کارگردان، خلاصه داستان، ژانر، سال انتشار، `slug`، میانگین امتیاز و تعداد نقدها است. مدل `Review` نیز ارتباط بین کاربر و فیلم را همراه با امتیاز و متن نقد ذخیره می‌کند.

## اجرای پروژه

سپس با دستورهای زیر وابستگی‌ها را نصب کرده و پروژه را اجرا کنید.

```bash
npm install
npm run dev
```

بعد از اجرای سرور، با ارسال درخواست `GET /` می‌توان از فعال بودن API مطمئن شد. همچنین فایل `Seed/movieseed.js` شامل چند فیلم نمونه است که برای وارد کردن اطلاعات اولیه به پایگاه داده استفاده می‌شود.
